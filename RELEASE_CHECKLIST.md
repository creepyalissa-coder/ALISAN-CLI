# Public Release Checklist

- [ ] Confirm the lawful rights holder for every source file, logo, screenshot, and asset.
- [ ] Verify third-party code and assets permit the intended distribution.
- [ ] Add official licensing and security contact addresses.
- [ ] Review the complete Git history for secrets, credentials, personal data, and confidential target information.
- [ ] Test installation from a clean Termux/Linux environment.
- [ ] Test every menu option and document observed behavior.
- [ ] Add automated tests where practical.
- [ ] Verify generated reports are not accidentally committed.
- [ ] Record exact dependency versions and verified licenses.
- [ ] Tag and archive the exact release source.
- [ ] Obtain legal review of the custom source-available license before commercial sale.

A copyright notice and repository history can help document authorship, but do not independently establish ownership of third-party material or replace a signed commercial agreement.
