# Security Policy

## Scope
This policy covers security issues in ALISAN-CLI itself.

## Reporting
Report suspected vulnerabilities privately to the project maintainer using an official security contact address published by Alisan Tech. Do not include credentials, personal data, or confidential target details in public issues.

Add and maintain an official security contact before announcing a formal vulnerability-response service.

## Authorized testing
Only test systems and networks you own or have explicit permission to assess. The existence of this tool is not authorization to test third-party infrastructure.

## Support status
This is an early-stage project. No service-level agreement or guaranteed security-maintenance window is implied.
