# Changelog

## 1.2.0 — Input validation and safer request handling
- Added hostname, HTTPS URL, and TCP port validation.
- Rejects non-global destinations for HTTPS checks.
- Disabled automatic redirect following for HTTPS checks.
- Added bounded network timeouts and unit tests.
- Improved report index output and updated release documentation.

## 1.1.0 — Initial public repository snapshot
- Added interactive command-line menu.
- Included Host Manager, Domain Checker, Network Tools, Security Scanner, and Report Engine modules.
- Added dependency list and initial public documentation.
